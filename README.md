<p><strong>Binance C2C is a peer-to-peer marketplace where Binance users buy and sell crypto assets directly with one another.</strong> Unlike spot trading pairs such as BTC/USDT, C2C is mainly designed for exchanging fiat currency for cryptocurrency.</p>

<p>For example, if you want to use a supported local fiat currency to buy USDT, you can find a seller on Binance C2C who accepts your preferred payment method.</p>

<p>After an order is created:</p>

<ol>
